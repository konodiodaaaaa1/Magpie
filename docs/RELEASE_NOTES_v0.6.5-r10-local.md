# Magpie 0.6.5 r10 local

主页提供 Front Edge Sync 和目标帧率设置。Front Edge Sync 默认开启、目标默认 60 FPS；VRR 暂时隐藏并停用。设置自动保存，重新启用效果组生效。中英文与繁体中文说明同步提供。

- DLSSNR 核心及其上游图像参数原本会使缓存失效的实时修改，现合并连续编辑后完整停用效果组，等待 500 毫秒再以新参数重新启用；旧 NR 实例不接收这些修改。残差合成及下游参数保持原有实时行为，原有“重启”参数仍需手动应用。手动停用、切换效果组或关闭源窗口会取消等待中的重启。
- FrameRate Filter 默认「基于 Front Edge Sync」；开启同步时强制跟随并锁定，关闭后可选择「自定义」启用帧率滑条。自定义数值保留，跟随模式不会叠加旧的自定义上限。
- 光流档位「质量」取消“推荐”备注，保留「均衡（推荐）」及高质量／最高质量的开销备注。
- 主页同步说明精简。
- 无 FG：提前准备图像，在实际 Present 提交边界定时；内容与工具栏共用节奏，限制待呈现结果积压。
- DLSSFG：稳定补帧前的真实帧输入，保留生成帧／真实帧队列的顺序与输出调度。
- XeSSFG／MFG：通过 XeLL 的输入等待与限帧接口接入，按倍率换算 SDK 目标，避免外层再次限制生成帧输出。
- VRR 暂缓：隐藏主页入口，并忽略旧配置中已开启的 VRR 值。撤回全屏焦点实验，恢复源窗口保持前台的原有行为；相关呈现代码保留供后续研究。
- 普通 DXGI／XeSS 容量不足时，用已有容量事件唤醒消息循环，减少纯轮询带来的额外等待；FES 截止时间及 FG 调度保留。
- 保留 REALTIME GPU 调度优先级，以及 r9 的捕获连续性和性能分析器修复。

目标设为 80 FPS，配合 2 倍 FG 时控制 80 FPS 基础输入，名义输出 160 FPS。手动设置 0 时按显示器刷新率自动设置，FG 按倍率折算；应用配置与捕获后端已有的更低上限继续生效。已保存的主页设置保留。

完整说明见 [Front Edge Sync](FRAME_SYNC_GUIDE.md)，包含 RTSS 配合、延迟代价、VRR 暂缓说明和测试建议。编译与 CPU 检查通过；没有运行 Magpie 或进行 GUI／GPU 测试，实机效果由用户确认。
