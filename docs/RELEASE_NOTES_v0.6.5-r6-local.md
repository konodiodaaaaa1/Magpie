# Magpie 0.6.5 r6 local

在 r5 fix2 基础上实施已确认的交互和预设调整。HDR 按用户决定留到后续版本，本次不加入 TrueHDR、HDR 转换效果器或 HDR 输出设置。

## 使用变化

- 简体中文、繁体中文、英文界面将“缩放模式”统一改为“效果组”。效果组包含效果器；快捷键和延时操作使用“启用／停用效果组”，窗口／全屏表示输出模式。“缩放倍数”等尺寸设置保留原义。配置键、效果 ID、导入格式保持兼容。
- 主窗口参数页和工具栏实时参数页：同一滑条两次按下间隔不超过 **170ms** 时，恢复**效果器自身默认值**。不会恢复效果组覆盖值或本次运行初始值。拖动、跨控件、取消输入会中断判断；一对点击只触发一次。Live / Restart 以及参数自动保存仍按原有规则生效。
- Jinc 的 sinc 步长改为 0.005，使默认值 0.825 能准确表达。运动可视化原生缺省增益与效果器声明的 0.08 一致。
- 新建配置／重置默认组时，DLSSNR 组只包含 DLSSNR_AI_Filter，移除其前面的 FrameRate_Filter。仓库中的同名 JSON 导入预设同步；其他组和参数不变。**已有用户效果组不会被自动改写**；需要时可手动删除其中的限帧器。

## 对比

工具栏“对比 / Compare”按钮单击切换，悬停仅显示名称，不再显示说明。每次新运行默认关闭。快捷键默认为 **Alt + Shift + C**，可在“主页 → 工具栏快捷键设置 → 对比”中修改，沿用现有快捷键编辑、冲突检测和保存方式。

快捷键与按钮切换同一对比状态；通过现有运行会话校验后执行，并主动重绘当前稳定图像，不为切换重新加载效果。原图按当前输出矩形进行基础双线性适配。

每次成功切换后，右下角立即显示“原图”或“处理后”，无淡入；保持 2 秒，再用 500ms 线性淡出并隐藏。连续切换按最后一次重新计时，按钮和快捷键一致。角标不接收鼠标输入，静态内容下也按时消失。移除参数页里的对比说明，不新增其他说明提示。

启用期间仍调用完整效果链并消费补帧队列，不销毁效果器、停用补帧或主动重置历史。普通呈现和 DLSSFG 在前端选择原图；XeSSFG 仍接收处理结果，再通过独立覆盖层显示原图。原图分支保留真实捕获帧；DLSS 生成帧位置重复使用此前捕获图像，不把生成帧当成原始帧。

普通截屏保存当前选择的原图或效果图，不带工具栏和光标；右键导出仍来自指定效果器／通道。XeSS 的处理图截屏取提交给 SDK 的最近真实帧，不承诺捕获 SDK 内部生成的某一显示帧。背景相关的光标跟随当前图像分支。

原图资源创建或打开失败时保留效果处理，对比不可用；运行中原图副本失效时退出对比。主页的问题详情沿用现有入口。共享纹理事务仅在 `AcquireSync` 返回 `S_OK` 时访问纹理，防止将超时当成已获得所有权；这一返回值判断符合 [Microsoft 的接口说明](https://learn.microsoft.com/en-us/windows/win32/api/dxgi/nf-dxgi-idxgikeyedmutex-acquiresync)。

为了随时切换，参考图缓存也在关闭对比时更新。会增加显存、复制和同步开销；当前按输出尺寸缓存 RGBA8，单槽路径额外约 4 张图，四槽路径约 8 张。以 3840×2160 估算，像素存储分别约 **126.6MiB／253.1MiB**，未计驱动开销。对比不用于测量“关闭效果后”的省电或性能收益。改变几何形状的效果不保证原图与处理图逐像素对应。

## 验证范围

Release x64 完整构建通过，已部署到 `release/v0.6.5-r6-local/Magpie-v0.6.5-r6-local-x64` 并生成同名 ZIP。目录与 ZIP 的 235 个文件均通过 manifest／SHA256 核对，170 个效果器源码与发行文件一致。

“对比”名称与快捷键更新已完成覆盖部署，15 个语言候选值逐项匹配实际 PRI，记录见 [对比快捷键更新](experimental/todos/20260905-v0.6.5-r6-comparison-shortcut.md)。随后角标的 2 秒停留／500ms 淡出更新也已完成覆盖部署，三种语言共 6 个新增文案与实际 PRI 一致，最新产物及校验记录见 [对比角标更新](experimental/todos/20260905-v0.6.5-r6-comparison-badge.md)。

已完成的无界面检查：170ms 手势边界及取消逻辑、参考图计算着色器离线编译、三种语言资源键与占位符、268 个修改文案在实际 PRI 中的值、报错映射、XAML／项目 XML、JSON 预设差异。完整构建与部署结果记录在 [r6 实施记录](experimental/todos/20260905-v0.6.5-r6-TODO.md)。

按用户要求，不启动 Magpie、不使用 computer-use；实际交互、画质和 GPU 性能由用户验收。尤其需要在 DLSSFG／XeSSFG 上确认后台帧计数持续、切回无历史重置，以及 XeSS 覆盖期间驱动没有因遮挡而停止生成。源码保留处理调用不等于已完成这项实机验证。

建议优先查看：两个参数页双击重置、DLSSNR 默认组、连续切换对比、静态／动态内容、尺寸变化、截屏与当前分支、补帧后台计数。
