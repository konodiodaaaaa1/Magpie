# v0.6.5 r2 fix3 TODO：参数列分隔线

基线：当前 `0.6.5` 分支上的 v0.6.5 r2 fix2 工作树。

## 目标

- [x] 在参数 Flyout 的每两个相邻可见列之间增加 1 DIP 竖向分隔线。
- [x] 分隔线使用主题画刷 `ControlStrokeColorDefaultBrush` 和低透明度，兼容亮色与暗色主题。
- [x] 分隔线位于原 16 DIP 列间距中央，不压缩 260 DIP 参数内容宽度。
- [x] 第一列不显示前置分隔线，最后一列外侧不显示边框；单列效果不显示分隔线。
- [x] 参数显隐导致整列隐藏或恢复时，重新计算分隔线位置，不保留多余线条。
- [x] Release x64 完整构建通过。
- [x] 覆盖部署 `v0.6.5-r2-local` 并核对版本、ZIP 及文件清单。
- [ ] 在实际 UI 中检查 DLSSNR 两列、ImageAdjustment 三列、亮/暗主题和不同 DPI 下的线条观感。

## 设计结论

每个可见分组保存 `ShowLeadingSeparator` 状态：第一个可见分组为 `false`，之后的可见分组为 `true`。分隔线绘制在后续列左侧，并用 `-8 DIP` 外边距移动到 16 DIP 列间距中央，因此既不会占用参数内容宽度，也不会在 Flyout 最外侧形成边框。该状态与列宽在同一次布局刷新中更新。
