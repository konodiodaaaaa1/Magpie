# v0.6.5 r2 fix4 TODO：参数列间距

基线：当前 `0.6.5` 分支上的 v0.6.5 r2 fix3 工作树。

## 目标

- [x] 将参数 Flyout 的可见列间距由 16 DIP 调整为 24 DIP。
- [x] 将 ViewModel 的总宽度和窄窗口压缩计算同步改为 24 DIP，避免内容宽度与实际布局不一致。
- [x] 将 fix3 分隔线的偏移由 `-8 DIP` 改为 `-12 DIP`，继续位于列间距中央。
- [x] 不改变默认 260 DIP 列宽、最小 120 DIP 列宽及水平滚动禁用策略。
- [x] Release x64 完整构建通过。
- [x] 覆盖部署 `v0.6.5-r2-local` 并核对版本、ZIP 与文件清单。
- [ ] 在实际 UI 中检查 DLSSNR 两列与 ImageAdjustment 三列的间距和分隔线位置。

## 设计结论

列间距同时存在于 XAML 排列和 ViewModel 的 `ContentWidth` 计算中，两处必须保持一致。24 DIP 间距的中心距离后续列左边缘 12 DIP，因此分隔线使用 `Margin="-12,0,0,0"`，不会占用参数列自身宽度。
