# 0.6.5 r6 local 实施记录

用户于 2026-09-05 授权将已讨论的待执行内容归入 r6，完成后本地部署 r6 local。运行与画质验收由用户负责，不使用 computer-use。

## 实施范围与状态

- [x] 面向用户的“缩放模式”统一为“效果组”，启用动作、输出模式与尺寸缩放区分；配置键和效果 ID 保持兼容。
- [x] 两套效果参数滑条以 170ms 判断双击，恢复效果器自身默认值，保留 Live / Restart 与自动保存。
- [x] Jinc 步长能够表达 0.825；运动可视化原生缺省增益与 0.08 声明一致。
- [x] 内置默认 DLSSNR 组移除 FrameRate_Filter；同名导入预设同步，其他默认参数不变。
- [x] 工具栏原图对比，保留后台效果链和补帧处理调用，切换不重建效果；补帧实际持续行为由用户验收。
- [x] 对比截图、背景相关光标、状态提示与资源同步。原图锁失效可禁用该分支并继续效果处理；正常的前端零等待超时继续重试。
- HDR 管理式输出方案：用户明确选择留到后续版本，不纳入 r6。本次不新增 HDR 控件或处理路径。
- [x] Release x64 编译、必要的静态检查、r6 local 完整包与本地部署。

保留 r5 现有修改、r5 部署包及用户配置。实施前相关文件副本位于工作区 `.tools/r6/baseline`。

## 完成记录

- 完整 MSBuild Release x64 构建退出码为 0，最终控制台日志无编译警告或错误。EXE 文件／产品版本均为 `0.6.5-r6-local`。
- 170ms 包含边界、170ms 以上拒绝、跨滑条、三连击只消费一对、拖动返回原位、原始拖动标记和取消输入检查通过。检查的是独立输入判定器，未运行 GUI。
- 参考图计算着色器通过 FXC `cs_5_0`、严格模式、警告视为错误的离线编译。
- 英文／简体／繁体资源分别为 607／607／596 个唯一键，既有键与占位符保留。268 个改动后的语言候选值逐项匹配实际 `resources.pri`；全部 ErrorService 消息引用可解析。
- 170 个随包效果器 HLSL 与源码逐字节一致。JSON 预设仅移除 DLSSNR 组内 FrameRate_Filter，其他组未改写。
- 最终目录和 ZIP 共 235 个文件，逐项核对 manifest、大小和 SHA256；EXE、PRI、辅助程序与完整构建输出一致。未打包 cache、logs、用户 config 或调试符号。
- 未启动 Magpie，未使用 computer-use，未进行 GPU、画质或真实界面验收。XeSS 不透明覆盖下的驱动行为仍需用户验证。
