# r6 对比角标更新

用户要求对比切换后的右下角角标立即显示“原图／处理后”，保持 2s，再于 500ms 内淡出；不新增其他说明提示，覆盖 r6。

- 移除参数页中的对比说明及持续显示的“对比中”角标。
- 成功通过按钮或 Alt + Shift + C 切换后立即显示对应状态；首次运行不显示，切换失败不启动角标。重复切换更新文本并重新计时。
- 使用单调时钟按实际经过时间计算透明度：前 2s 为 1，随后 500ms 从 1 线性降至 0；文字及背景一起淡出。按当前文案计算尺寸，避免首帧自动测量隐藏及换文案时裁切。
- 对比关闭后仍显示短暂的“处理后”；角标无输入、无焦点且不存储窗口位置。
- 过期后的清除会请求最后一帧重绘；DLSSFG 静态内容时也允许稳定前端图像的叠加层重绘，不消费后台呈现队列，不重载效果。
- 简体、繁体、英文状态分别为原图／处理后、原圖／處理後、Original／Processed。
