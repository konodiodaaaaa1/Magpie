## 1. 决策摘要

- 将启用 `Adjust Input Resolution` 时的**颜色输入降采样**从当前 footprint area/box，替换为按缩放比例扩宽 support 的可分离 `Lanczos-2 AA`。
- 将低分辨率 DLSSNR 残差回到原始分辨率的**残差上采样**从当前可分离 `Lanczos-3 6+6 taps`，替换为可分离 `Catmull-Rom 4+4 taps`。
- 不新增用户参数和算法选择菜单；r5 直接替换固定算法。
- 不采用单 pass Mitchell 9-fetch，不引入硬件 linear sampler，不增加 anti-ringing clamp。
- 不修改 motion、confidence、inverse-depth 的降采样规则，不修改 NGX 参数、Frame Guidance 合同或残差控制参数的语义。
- Lanczos-2 AA 采用“先垂直、后水平”的顺序，复用现有 `RGBA16F` 残差中间纹理；不新增中间纹理显存。

## 2. 当前源码事实

主要实现位于 `src/Magpie.Core/DLSSNRFilter.cpp`，效果描述文件 `src/Effects/DLSSNR/DLSSNR_AI_Filter.hlsl` 只提供参数和占位 pass，实际重采样由原生 backend 完成。

当前启用输入分辨率调整后的颜色路径为：

```text
originalFull
  -> footprint area/box DownsampleColor
  -> reducedInput (sharedInput11, RGBA8)
  -> DLSSNR / NGX
  -> reducedDenoised (sharedOutput11, RGBA8)

residualLow = reducedDenoised - reducedInput
  -> horizontal Lanczos-3, 6 taps
  -> horizontalResidual11 (RGBA16F, fullWidth × reducedHeight)
  -> vertical Lanczos-3, 6 taps
  -> residual controls + originalFull
  -> final RGBA8
```

需要澄清：当前没有独立的“残差下采样”阶段。缩小的是送入 DLSSNR 的原始颜色；残差只在两个低分辨率颜色之间形成，然后被上采样。

### 2.1 当前颜色降采样

- `COLOR_DOWNSAMPLE_HLSL` / `DownsampleColor` 位于当前文件约 158–203 行。
- 每个目标像素枚举与其 footprint 相交的源像素，按几何覆盖面积加权并归一化，属于 scale-aware area/box。
- `PrepareInput` 约 1401–1450 行执行单次 compute dispatch，直接写入 `sharedInput11`。
- 输入 SRV 为非 sRGB `R8G8B8A8_UNORM` 或 typed `B8G8R8A8_UNORM`；所有运算发生在存储的 SDR 编码值域，BGRA typed SRV 已返回逻辑 RGBA 分量。

### 2.2 当前残差上采样

- `RESIDUAL_HORIZONTAL_HLSL` 约 271–324 行：在低分辨率读取 `ReducedDenoised - ReducedColor`，用 6-tap Lanczos-3 水平放大。
- `RESIDUAL_VERTICAL_COMPOSITE_HLSL` 约 326–457 行：用 6-tap Lanczos-3 垂直放大，然后执行 Residual Multiplier、正负残差控制、HSL 控制和原图回叠。
- `CompositeResidual` 约 1592–1660 行：先 dispatch `fullWidth × reducedHeight`，再 dispatch `fullWidth × fullHeight`，最后将 `compositeOutput11` 复制到效果输出。
- `horizontalResidual11` 是 `R16G16B16A16_FLOAT`，尺寸为 `fullWidth × reducedHeight`。
- 即使百分比为 100%，只要启用了输入分辨率调整，就仍进入 residual reconstruction，以保证 Residual Multiplier 等参数有效；两个 shader 目前有 equal-extent 快路径。

### 2.3 明确保持不变的 Guidance 降采样

- motion：area 平均；有 confidence 时按 confidence 加权，并按目标/源尺寸缩放位移。
- confidence：area 平均。
- inverse depth：保留 footprint 内最大值，即最近表面。
- 上述规则位于 `GUIDANCE_DOWNSAMPLE_HLSL`，不能因为颜色改用 Lanczos-2 而机械替换。负权重颜色核不适合 depth 的保守最近表面语义，也可能使 confidence 越界。

## 3. r5 目标数据流

```text
originalFull
  -> vertical scale-aware Lanczos-2 AA
  -> resampleIntermediate (RGBA16F, fullWidth × reducedHeight)
  -> horizontal scale-aware Lanczos-2 AA
  -> reducedInput (RGBA8)
  -> DLSSNR / NGX
  -> reducedDenoised (RGBA8)

reducedDenoised - reducedInput
  -> horizontal Catmull-Rom, 4 taps
  -> resampleIntermediate (同一张 RGBA16F 纹理)
  -> vertical Catmull-Rom, 4 taps
  -> 现有 residual controls + originalFull
  -> final RGBA8
```

两个阶段不会重叠：颜色降采样在 NGX 前使用中间纹理，残差上采样在 NGX 完成后覆盖它。因此同一纹理可以安全复用，其尺寸和格式正好满足两条路径。

## 4. 算法规格

### 4.1 Scale-aware Lanczos-2 AA 降采样

每个轴独立计算。设该轴缩放比例为：

```text
scale = targetExtent / sourceExtent, 0 < scale <= 1
sourcePosition = (targetPixel + 0.5) / scale - 0.5
support = 2 / scale
```

源样本 `i` 的权重：

```text
d = (i - sourcePosition) * scale
L2(d) = sinc(d) * sinc(d / 2),  |d| < 2
L2(d) = 0,                       |d| >= 2
sinc(0) = 1
sinc(x) = sin(pi*x) / (pi*x)
```

实施约束：

- 枚举范围使用 `ceil(sourcePosition - support)` 到 `floor(sourcePosition + support)`。
- 每轴都除以实际离散权重和，保持 DC/常量场不变；权重和接近零时使用安全分母。
- 边界使用现有 clamp-to-edge 坐标规则；权重仍按 unclamped 样本位置计算，重复读取被夹取的边缘像素。
- 最低 25% 比例下 support 为 8 个源像素，每轴最多约 16–17 taps；必须保留有界动态循环，不能退化为二维 16×16 直接卷积。
- 先执行垂直 pass：`fullWidth × reducedHeight`；再执行水平 pass：`reducedWidth × reducedHeight`。
- 中间结果保持 `RGBA16F`，不在第一 pass `saturate`，避免截断 Lanczos 负 lobes；最终写入 `sharedInput11` 的 UNORM UAV 时才发生格式约束。
- alpha 与 RGB 使用相同权重，不假定输入必为不透明。

### 4.2 Catmull-Rom 4+4 残差上采样

保持当前 half-pixel 坐标约定：

```text
reducedPosition = (fullPixel + 0.5) * reducedExtent / fullExtent - 0.5
center = floor(reducedPosition)
```

每轴只读取 `center-1`、`center`、`center+1`、`center+2` 四个 tap。Catmull-Rom 即 Mitchell-Netravali family 的 `(B,C)=(0,0.5)`：

```text
x = abs(x)
K(x) =  1.5*x^3 - 2.5*x^2 + 1,                  x < 1
K(x) = -0.5*x^3 + 2.5*x^2 - 4*x + 2,       1 <= x < 2
K(x) = 0,                                        x >= 2
```

实施约束：

- 水平 pass 直接对每个 tap 计算 `ReducedDenoised - ReducedColor` 后加权，继续避免先把完整低分辨率残差另存一张纹理。
- 垂直 pass 读取四个 `RGBA16F` 中间样本，并保持现有 `ApplyResidualControls`、alpha 继承和最终回叠代码不变。
- 两个 pass 都按实际权重和归一化，保留现有 clamp-to-edge 边界行为。
- 使用四次显式 `Load`/轴和三次多项式，不创建 sampler，不依赖硬件 cubic filtering。
- equal-extent 快路径必须保留：100% 时水平 pass 直接形成低分辨率残差，垂直 pass 直接读取，不进行无意义的四 tap 重建。
- 不加入 neighborhood clamp。Catmull-Rom 仍有负 lobes，但先前代理测试的阶跃过冲低于当前 Lanczos-3；是否需要 clamp 留给独立实验。

### 4.3 100% 和未启用缩放的合同

- `enableInputResolutionScaling == false`：继续走现有原分辨率 DLSSNR 直接输出路径；不执行颜色降采样或残差 Catmull-Rom 合成。
- `enableInputResolutionScaling == true && inputResolutionPercent == 100`：颜色准备必须是精确 identity/格式转换，但仍执行 equal-extent residual composition，以保持所有 residual 参数有效。
- RGBA 输入在 100% 时优先 `CopyResource` 到 `sharedInput11`；BGRA 输入使用现有 typed SRV → RGBA UAV conversion。初始化时应保证所需 view/shader 在该组合下存在。

## 6. 已知风险与防错条件

- Lanczos-2 有负 lobes。中间结果不得提前 clamp；最终 RGBA8 写入会自然限制范围，但应检查黑白边、发光边缘和 UI 文字附近的轻微 ringing。
- Catmull-Rom 也有负 lobes。其目标是比 Lanczos-3 少噪声和 halo，不是实现零振铃；零振铃档仍应由 bilinear 承担，而非在 r5 偷加隐藏 clamp。
- 输入降采样改变的是 DLSSNR 的语义输入，最终差异不等同于普通 resize PSNR；必须检查模型是否把残余 ringing/纹理当作材质特征。
- 颜色仍在非线性 SDR 存储值域滤波。r5 不顺带引入线性光转换，否则会同时改变模型输入分布和残差含义。
- `inputResolutionPercent` 最低 25%，动态 tap 数有明确上界；如果将来放宽参数范围，必须重新评估循环上界和 watchdog 风险。
- vertical-first 与此前 horizontal-first 的离线原型在理想可分离卷积下等价，但 FP16 中间量和边界量化顺序可能造成 1 LSB 级差异；最终实现必须重新测量，不能复用旧结果冒充实测。
- 当前工作树已有大量 r4 等用户改动；执行时只修改命中的 DLSSNR 重采样区域，不覆盖或格式化无关代码。

### 7.4 频域和代理质量复核

先前代理测试给出的预期范围：

| 上采样核 | gain75 | 白噪声 RMS gain | 残差阶跃过冲 |
|---|---:|---:|---:|
| Catmull-Rom | 0.792–0.800 | 0.899–0.903 | 4.4–7.4% |
| Lanczos-3（当前） | 0.890 | 0.944–0.946 | 9.0–11.8% |

输入降采样的先前预期：Lanczos-2 AA 的目标 Nyquist 75% 处增益约 `0.769–0.770`，白谱 alias 功率代理约 `4.5%`；当前 area 的 alias 代理随比例约 `8.9–21.4%`。最终实现应重新生成曲线和数值，确认没有因为坐标、scale 或 tap 边界错误偏离预期。
