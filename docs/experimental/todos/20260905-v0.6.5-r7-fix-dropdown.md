# r7 fix 补充：实时参数下拉框点击外部收起

日期：2026-09-05。

## 原因及修改

实时参数使用 ImGui 的标准 BeginCombo。原有输入路由在弹窗展开后只保留最上层弹窗的命中区域；点击弹窗外部时，既未命中该区域，也没有已捕获的按键，因此鼠标按下事件被丢弃。ImGui 没有收到应当关闭下拉框的点击。

- 随最后一次成功 Present 保存“是否有展开弹窗”的状态。弹窗展开时，外部点击也进入原有按下／抬起输入队列，由 ImGui 正常关闭；不把这次点击当成选择某个参数值。
- WndProc 仍只记录输入，不直接修改 ImGui 弹窗栈。继续使用呈现成功后的区域与状态，避免把尚未显示的新帧当成可点击界面。
- 焦点丢失、输入取消和清理面板时关闭非模态弹窗，模态弹窗保留其原有行为。
- 参数草稿、Live／Restart 判定和自动保存逻辑未改动；只有实际选择了新值才产生参数修改。
- 共用输入层的上下文菜单同样获得正常的外部点击关闭行为。没有新增界面提示，也没有改变前一轮 DLSS 呈现调度修复。

源码只修改 `ImGuiImpl.cpp` 和 `ImGuiImpl.h`。已核对当前链接的 ImGui 1.91.8 源码：外部左键点击通过焦点处理关闭 popup，右键通过 ClosePopupsOverWindow 关闭；本次恢复这些输入所需的正常事件通路。
