# Magpie Experimental v0.6.0 Hotfix

This is an incomplete minimal hotfix package based on Magpie Experimental v0.6.0. It cannot be used as a standalone installation package.

Users who downloaded v0.6.0 during the first hour after its early-morning release may encounter blocked controls when stopping scaling during TensorRT warmup. Download `Magpie-v0.6.0-Hotfix-x64.zip`, fully exit Magpie, and replace the existing `Magpie.exe` in the v0.6.0 installation directory with the file from this package.

## Asset checksum

- `Magpie-v0.6.0-Hotfix-x64.zip`: `3F6AEAA17BC9B1B3F3F756756B8DBE32C876E1321DC07E123B62C4BFDEB31DD8`
